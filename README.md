# Excel Data Cleaning & Customer Data Analysis

A practical Excel project focused on cleaning, validating, organizing, and analyzing customer data.

## Project Overview

This project demonstrates how raw customer data can be transformed into a clean and structured dataset ready for analysis.

## What I Did

- Removed duplicate customer records
- Checked email and data quality
- Standardized customer information
- Organized the cleaned dataset
- Created a city-wise customer summary
- Calculated total and average purchases
- Prepared a data quality report

## Project Files

- `customer_data_report.xlsx` — Complete Excel workbook containing the cleaned data, city summary, and data quality report.
- `customer_data_cleaning_portfolio.pdf` — Visual presentation of the project.

## Skills Used

- Microsoft Excel
- Data Cleaning
- Data Processing
- Data Validation
- Data Analysis
- Spreadsheet Management

## Result

The final dataset is organized, readable, and structured for further analysis and reporting.
